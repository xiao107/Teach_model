1品牌化视觉主题（-gradient Design）

当前是单一蓝色。升级为「品牌渐变 + 双色系」体系，让产品有记忆点，同时保持克制：

品牌渐变#4F7CFF → #8B5CF6
主色#4F7CFF
辅色#8B5CF6
数据青#0EA5A4
强调橙#F59E0B

应用位置：Logo、"新建对话"按钮、发送按钮、AI 头像、active 指示条、欢迎页标题。渐变只用于"品牌触点"，大面积界面仍保持中性色。

2AI 回复卡片化 + 深色代码主题

助手回复从"纯透明文本"升级为轻卡片；代码块切换为深色主题（与 highlight.js 的 github-dark 配套），形成"聊天浅色 / 代码深色"的层次对比。

元素现状升级后
AI 回复容器透明无边框白卡片 + 1px 边框 + 极浅投影
代码块浅灰底浅色高亮#0D1117 深底 + github-dark 高亮 + 语言标签角标
行内代码浅灰淡紫底（呼应品牌辅色）
表格白底灰线表头渐变浅底 + 斑马纹 + 圆角阴影

3ECharts 图表主题统一

当前图表用 ECharts 默认配色，与界面脱节。注册全局自定义主题：

项方案
色板[#4F7CFF, #8B5CF6, #0EA5A4, #F59E0B, #EC4899]，分类图按序取色
网格线#EEF1F5 虚线，隐藏外框
字体继承界面字体栈，轴标签 12px #5C6470
柱/条顶部圆角 [6,6,0,0]，渐变填充（上深下浅）
tooltip白底、圆角 10px、品牌色轴指示线
入场动画animationDuration 600ms + cubicOut（与消息入场节奏一致）

4微交互与动效

消息

流式输出时打字机光标闪烁；完成后气泡轻微 settle 动画（scale 0.99→1）

按钮

发送按钮 hover 轻微放大 + 渐变位移；点击涟漪；发送中变为"停止"方块

加载

等待首 token 时显示三点跳动 + "正在思考"渐隐轮换，替代静态文本

侧边栏

会话项 hover 时图标微弹（translateX 2px）；删除按钮旋转入场

5欢迎页 Hero 升级

现状
静态 logo + 文本 + 三个白底示例条。干净但平淡，缺少"教学平台"的氛围感。
升级后
① 背景加极淡的双色 radial 光晕（品牌渐变 5% 透明度）
② Logo 加呼吸动画 + 渐变描边
③ 标题"AI 学生"四字用渐变文字
④ 示例条左侧加彩色图标徽章、hover 时箭头滑动

6暗色模式

tokens 已就绪，成本最低的高级感来源。新增 [data-theme="dark"] 变量组（背景 #0F1115 / 卡片 #171A21 / 边框 #262B36 / 文字 #E6E9EF），顶栏加"月亮/太阳"切换按钮，跟随系统 + 手动覆盖 + localStorage 记忆。图表主题同步注册 dark 变体。

7细节打磨清单

细节做法
空数据插图欢迎页与会话列表空态配轻量 SVG 插画（虚线圆 + 漂浮数据点）
滚动条hover 区才显形的悬浮式细滚动条
骨架屏历史会话加载时先渲染灰块骨架，避免闪烁
favicon补一个渐变菱形 SVG favicon（当前没有）
打印/导出对话支持导出为带样式的 HTML/PDF
a11y焦点环统一 2px 品牌色、对比度过 WCAG AA
